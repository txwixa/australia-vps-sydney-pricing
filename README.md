## 原生 IP 和双 ISP 住宅 IP，决定你能不能用

这两个词经常被混用，实际差别很大。

**原生 IP** 指这段地址在 IP 数据库里登记为澳大利亚本地 ISP 分配，而不是数据中心段。它比普通机房 IP 干净，注册本地服务、看本地流媒体通常没问题，但属性上仍可能被识别为商业宽带。

**双 ISP 住宅 IP** 更进一步，地址登记在两个本地运营商名下，风控数据库里更接近“真实家庭用户”。做 TikTok 养号、需要过平台身份校验的场景，这一档的存活率明显更高，价格也更贵。

WePC 的澳洲产品线里，AU Basic 和 AU Pro 是原生 IP，EXETEL 家宽和悉尼直播线路才是家宽属性。如果你只是想给澳洲客户看一个网站，原生 IP 完全够；如果是拿账号当资产在运营，省下的那 10 澳元最后可能赔在一个被封的号上。

需要提醒的是，任何商家都不能保证 IP 永久不被标记。测评里提到偶尔会遇到 IP 被标记的情况，联系客服换 IP 一般能解决，但这属于运营成本的一部分，不是故障。

**退款条款有三个版本，别按任何一版做计划。** 官网商店页面挂的是“30 Days Money Back Guarantee”；第三方测评里流传的是“3 天内、流量不超过 5%”和“3 天内、流量 10GB 以内”两个说法。三个版本差距太大，下单前开工单问清楚：窗口从付款算还是从开通算，流量按哪个口径统计，退款退到余额还是原路。

**热门机房会断货。** 香港、日本这类节点补货周期不固定，急着上线的话先选有货的机房，或者提前问客服补货时间。

**配置偏保守，不适合重负载。** 大部分 TikTok 专区套餐是 1 核 512MB 或 2 核 1GB 起步，跑 WordPress、小型数据库没问题，视频转码、大型数据库这类吃内存的活会上不去。要跑这些，直接看建站类的 Website 系列，4 核 4GB 起。

**客服在线时间是北京时间 9:00–21:00**，其余时间走工单，测评里提到的响应速度是 1–2 小时。有时区外的紧急故障，要按这个节奏安排。
